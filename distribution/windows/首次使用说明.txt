Minerva Windows 一键启动包
===========================

使用方法
1. 将整个压缩包解压到本地磁盘，路径尽量简短，例如 D:\Minerva。
2. 双击“启动 Minerva.bat”。
3. 首次启动会从包内准备 Python、PostgreSQL 和 Wiki.js，通常需要等待几分钟。
4. 浏览器会自动打开 http://127.0.0.1:30141。
5. 在 Minerva 设置中配置模型服务及 API Key，然后即可导入匿名化作业包测试。配置和会话只保存在当前 Minerva 文件夹内。
6. 使用结束后双击“停止 Minerva.bat”。

注意事项
- 本包仅支持 64 位 Windows 10/11。
- 所有服务只监听 127.0.0.1，默认仅本机可以访问。
- 包内没有开发者的 API Key、会话、学生信息、答卷或数据库；启动时也不会读取本机其他 Minerva/Pi 实例的数据。
- 程序运行依赖已经打包；配置和调用模型服务时仍然需要联网。
- 不要直接在压缩包中双击启动，必须先完整解压。
- 如果启动失败，请查看 logs\startup-error.log、web.stderr.log 和 data-api.stderr.log。
- Wiki.js 首次使用时可访问 http://127.0.0.1:3002 完成管理员初始化；未配置时知识图谱仍显示 Minerva 自有数据。
